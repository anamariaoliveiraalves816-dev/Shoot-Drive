# Demo Game Catalog

A simple HTML, CSS, and JavaScript project for showcasing playable demo games.

## Features

- Browse a catalog of demo-phase games.
- Launch demo links with a play counter.
- Submit new demo games using a local form.
- Data persists in browser localStorage.

## Usage

1. Open `index.html` in your browser.
2. Browse the demo game cards.
3. Click "Play Demo" to simulate launching a game and increment the play counter.
4. Submit your own demo game using the form.
